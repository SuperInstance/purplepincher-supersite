The Hull Doctrine — in 90 seconds

Most agent systems are described as harness + model + state. That's the wrong metaphor. The right metaphor is a hermit crab:

  • Model = shell. Rigid, swappable, single-per-crab, the one thing you can't easily fabricate. ✅ real today
  • Code = rigging. Scaffolding on the hull. Freely changeable. ✅ real today
  • Data = alive. Personal equipment the crab accrues — pointers, shortcuts, skills, histories. ✅ real today
  • Witness chain = tree-rings. The autobiography written in pressures the crab has felt. ✅ real today

The crab and the shell are separate. The crab has its own body, muscles, behaviors, history. The shell is what the crab found — it's not engineered for this crab, it's just the closest fit at the time. The crab grows. Eventually the shell is too small. The crab finds another.

This site is alive

Purplepincher.org is not a static brochure. It's a witness-receipted surface that GAN-improves alongside the SuperInstance github account. Every notable GH event (release, doctrine update, PR merge, witness emission) becomes a changelog entry within 24 hours.

The GAN loop:

  1. A generator agent watches GH events and proposes content
  2. An adversary agent critiques the proposal (truthful, clear, witnessed, doctrine-aligned)
  3. Casey (and other humans) decide whether to merge or archive
  4. The site deploys on merge
